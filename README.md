# AI-Driven Scheme Matching for Marginalized Entrepreneurs

Beginner-friendly full-stack prototype:
- Frontend: HTML, CSS, JavaScript
- Backend: Python FastAPI
- Database: SQLite
- Explainable AI-style matching engine
- Personalized scores, reasons, warnings, filters, feedback, demo profile

## Run

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn backend.main:app --reload
```

Open: http://127.0.0.1:8000

The included schemes are DEMO data. Verify official eligibility and links before production use.
